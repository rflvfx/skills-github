## 📋 Sobre

Automação de repositório: pipeline de CI, releases por tag, atualização de dependências e templates de contribuição.

## 📂 Conteúdo

- `.github/workflows/ci.yml` — testes em push/PR
- `.github/workflows/release.yml` — release por tag
- `.github/dependabot.yml` — updates semanais
- `.github/PULL_REQUEST_TEMPLATE.md` — padrão de PR
- `actions.md` — notas sobre Actions
